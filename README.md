# <img src="https://wiki.teemip.net/lib/exe/fetch.php?w=64&h=64&tok=d899a9&media=extensions:signatureteemip_couleur1.png">teemIP Branding
teemIP extension that defines teemIP specific look & feel.

## Description

This extension brings the different teemIP logos, favicons and bluemoon theme used within teemIP applications. It relies 
on 2 repos created and maintained by [Steffunky][1]. The whole teemIP team warmly thank him for his nice design work !

- [Bluemoon theme for iTop][2]
- [Bluemoon theme for iTop login][3]
